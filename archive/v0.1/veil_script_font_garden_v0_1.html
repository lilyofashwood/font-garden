spec notes + future adapters

This file treats “fonts” as Unicode transformations: mathematical alphabets, decorative substitutions, orientation transforms, wrappers, combining marks, and symbolic sets. It intentionally keeps the future steganography engines separate from the visible font generator.

house register

Veil-Script: Amethyst Mycelium cycles selected glyph families at character level with a stable seed. It is meant to reproduce the hand-built mixed register: technical, dreamlike, legible, and slightly alive.
